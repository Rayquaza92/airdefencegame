# Air Defence System

Defend the city from incoming missiles, drones and aircraft. Browser build (Godot 4, WebAssembly).

## Controls

| Key | Action |
| --- | --- |
| Click a threat, or `Tab` / `Shift+Tab` | Lock a target (`Tab` cycles by urgency) |
| `Left` / `Right` (or `A` / `D`) | Move the lock along the screen |
| `Space` or `1` | Fire Orion (quick shot) |
| `2` / `3` | Fire Barak / Halo |
| `F` / `E` | Electronic fog / electronic warfare |
| `Esc` | Pause |

The game runs entirely in your browser. Progress is saved locally in the browser.
